# 🕉️ सनातन ज्ञान-कोष एवं वैश्विक विज्ञान रिसर्च इंजन
### Sanatan Knowledge Hub & Global Science Research Engine

An authoritative, high-performance Next.js (App Router) + Tailwind CSS interdisciplinary research platform bridging ancient Vedic, Upanishadic, Darshanic, Astronomical, and Mathematical heritage with modern theoretical physics, cosmology, metallurgy, and artificial intelligence.

## ✨ मुख्य विशेषताएँ (Key Features)

### १. सम्पूर्ण १२+ वैज्ञानिक व संस्थान मास्टर डेटाबेस (Master Corpus Data)
- **निकोला टेस्ला (1907):** आकाश, प्राण व वोर्टेक्स डायनेमिक्स (तैत्तिरीयोपनिषद् २.१ - *तस्माद्वा एतस्मादात्मन आकाशः संभूतः*)।
- **नासा / रिक ब्रिग्स (1985):** AI नॉलेज रिप्रजेंटेशन व पाणिनीय अष्टाध्यायी (सूत्र १.१.१) का BNF कॉन्टेक्स्ट-फ्री व्याकरण।
- **इरविन श्रॉडिंगर (1944):** वेव समीकरण ($\Psi$), सुपरपोजिशन व अद्वैत चेतना (छान्दोग्योपनिषद् ६.८.७ - *तत्त्वमसि*)।
- **वर्नर हाइजेनबर्ग (1958):** अनिश्चितता का सिद्धांत व प्रेक्षक प्रभाव (कठोपनिषद् २.२.१५ - *तमेव भान्तमनुभाति सर्वं*)।
- **जे. रॉबर्ट ओपेनहाइमर (1945):** विश्वरूप दर्शन व नाभिकीय ऊर्जा विमोचन (श्रीमद्भगवद्गीता ११.१२, ११.३२ - *कालोऽस्मि लोकक्षयकृत्प्रवृद्धो*)।
- **कार्ल सागन / NASA (1980):** ८.६४ अरब वर्ष कॉस्मिक काल-चक्र व नटराज ताण्डव (श्रीमद्भगवद्गीता ८.१७ व सूर्यसिद्धान्त)।
- **CERN जिनेवा / फ्रिटजॉफ काप्रा (1975):** शिव नटराज ताण्डव व क्वांटम फील्ड वैक्यूम फ्लक्चुएशन (तैत्तिरीयोपनिषद् ३.१)।
- **श्रीनिवास रामानुजन (1920):** मॉक थीटा फंक्शन व ब्लैक होल क्वांटम एंट्रॉपी (ईशावास्योपनिषद् शान्ति मन्त्र - *ॐ पूर्णमदः पूर्णमिदं*)।
- **सर जे.सी. बोस (1902):** पादप चेतना व ६० GHz मिलीमीटर तरंग संचरण (मनुस्मृति १.४९ - *अन्तःसंज्ञा भवन्त्येते सुखदुःखसमन्विताः*)।
- **अल्बर्ट आइंस्टीन & एस.एन. बोस (1924):** बोस-आइंस्टीन सांख्यिकी व एकात्मता (ऋग्वेद १.१६४.४६ - *एकं सद् विप्रा बहुधा वदन्ति*)।
- **डेविड बोम (1980):** होलोग्राफिक यूनिवर्स व इम्प्लिकेट ऑर्डर (बृहदारण्यकोपनिषद् ५.१.१)।
- **नील्स बोर (1927):** कॉम्पलीमेंटैरिटी सिद्धांत व द्वैत-अद्वैत पूरकता (ईशावास्य ५ व माण्डूक्य ७)।

*प्रत्येक कार्ड में मूल संस्कृत मन्त्र, पदच्छेद/अन्वय, वैज्ञानिक भावार्थ एवं मूल प्रकाशित शोधपत्र का नाम स्पष्ट रूप से उपलब्ध है।*

### २. उन्नत ऑडियो प्लेयर एवं टेक्स्ट सेलेक्शन इंजन (Audio & Player Engine)
- **सटीक मन्त्र वाचन:** किसी भी डमी साउंड के स्थान पर प्रत्येक कार्ड का मूल मन्त्र, पदच्छेद व वैज्ञानिक भावार्थ स्पष्ट आवाज़ में पढ़ा जाता है।
- **गति नियंत्रण (Speed Control):** संस्कृत मन्त्रों के शांत व स्पष्ट उच्चारण हेतु डिफ़ॉल्ट वाचन गति **0.85x** पर सेट है (0.75x, 0.85x, 1.0x, 1.25x विकल्प उपलब्ध)।
- **बॉटम फ्लोटिंग प्लेयर (Bottom Floating Player):** स्क्रीन के निचले भाग में (`fixed bottom-4 left-1/2 -translate-x-1/2 z-50`) साफ-सुथरा प्लेयर जिसमें Play, Pause, Stop, गति चयन व मन्त्र शीर्षक स्पष्ट दिखाई देता है।
- **कार्ड-स्तरीय बटन:** प्रत्येक कार्ड में एक स्पष्ट **'🔊 मन्त्र सुनें'** बटन।
- **टेक्स्ट सेलेक्शन वाचन:** स्क्रीन पर किसी भी श्लोक या पंक्ति को सेलेक्ट करने पर तुरंत **'🔊 चयनित पाठ सुनें'** का विकल्प।

## 🚀 स्थानीय विकास एवं सेटअप (Getting Started)

```bash
# 1. रिपॉजिटरी क्लोन करें
git clone https://github.com/PRATEEKSINGH-88/sanatan-scholar-engine.git

# 2. प्रोजेक्ट डायरेक्टरी में जाएं
cd sanatan-scholar-engine

# 3. निर्भरताएं इन्स्टॉल करें
npm install

# 4. डेवलपमेंट सर्वर प्रारंभ करें
npm run dev
```

ब्राउज़र में [http://localhost:3000](http://localhost:3000) खोलें।
